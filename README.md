#  Instagram UI Clone (Flutter)

A clean **Instagram UI Clone** built using **Flutter**.  
This project focuses only on **UI design** (no backend).

---

##  Features
- Home Feed UI
- Stories Section
- Post Layout
- Profile Screen UI
- Bottom Navigation Bar
- Dark Theme
